# Field Service Management System

## Setup Instructions

This project is built with React, TypeScript, and Vite. To run it locally, you need to have **Node.js** installed.

### 1. Install Node.js
If you don't have Node.js installed, download it from [nodejs.org](https://nodejs.org/) and install the LTS version.

### 2. Install Dependencies
Open a terminal in this directory and run:

```bash
npm install
```

This will download all the necessary libraries (React, Vite, Lucide Icons, etc.) listed in `package.json`.

### 3. Run the Application
Start the development server:

```bash
npm run dev
```

Then open your browser to the URL shown (usually `http://localhost:5173`).

---

## Troubleshooting

### "npm is not recognized"
If you see this error, it means Node.js is not installed or not in your system PATH. Please install Node.js as described above.

### Red Squiggly Lines in Code
If you view the code in an editor and see many errors, it is because `npm install` has not been run yet. Once specific dependencies are installed, these errors will disappear.
